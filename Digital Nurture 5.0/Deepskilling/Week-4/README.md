# Exercises Completed

## Question 1 – JWT Authentication

### Objective

Implement JWT Authentication in an ASP.NET Core Web API.

### Features

- JWT Token Generation
- User Login API
- Swagger Integration
- Secure Token Creation
- Authentication Middleware

---

## Question 2 – Secure API Endpoint

### Objective

Protect Web API endpoints using JWT Authentication.

### Features

- Protected Employee API
- Authorization using JWT
- CRUD Operations
- Swagger Authorization
- Unauthorized Access Handling

---

## Question 3 – Role-Based Authorization

### Objective

Implement Role-Based Authorization using JWT.

### Features

- Admin Login
- User Login
- JWT Role Claims
- Admin-only APIs
- User-only APIs
- Shared APIs for Admin and User
- Role-Based Security

---

## Question 4 – JWT Expiry Handling

### Objective

Demonstrate JWT Token Expiration and handling of expired tokens.

### Features

- Configurable Token Expiry
- Expired Token Detection
- 401 Unauthorized Response
- Protected APIs
- Authentication Failure Handling
