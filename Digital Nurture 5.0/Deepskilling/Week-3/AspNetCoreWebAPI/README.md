# Week 3 - ASP.NET Core 8.0 Web API

## Overview

This week focuses on ASP.NET Core 8.0 Web API concepts and implementation.

## Topics Covered

- RESTful Web API
- HTTP Request and Response
- HTTP Action Verbs
- HTTP Status Codes
- Swagger
- Postman
- Routing
- Custom Model Classes
- Custom Authorization Filters
- Custom Exception Filters
- CRUD Operations
- JWT Authentication
- Bearer Tokens
- JWT Expiration
- Role-Based Authorization

## Hands-on Exercises

The ASP.NET Core Web API mandatory hands-on exercises include:

- Creating a Web API with GET, POST, PUT and DELETE methods
- Testing APIs using Swagger and Postman
- Creating Employee, Department and Skill models
- Implementing Custom Authorization Filters
- Implementing Custom Exception Filters
- Performing CRUD operations
- Implementing JWT Authentication
- Testing JWT expiration
- Implementing Role-Based Authorization
